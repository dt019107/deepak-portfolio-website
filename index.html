About Me

I start with the user's friction,
then design backward to the screen

Every project begins by understanding where people get stuck. I map messy user flows, explore solutions in low-fidelity, and stress-test interactive prototypes before finalizing tokenized design systems and dev specs.

Design Systems

Component-driven UI kits in Figma with strict tokens, auto-layout, and dev-ready handoff specs.

User Research

Field interviews & usability testing to uncover real blockers (like 14 driver tests for Ola Partner).

Interactive Prototyping

Micro-interactions and clickable prototypes in Figma and code to validate flows before engineering writes a line.
